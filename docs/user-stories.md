TALLER - METODOLOGÍAS ÁGILES

Épica 1: Gestión de productos
Abarca: Registrar, consultar, actualizar y desactivar tenis.

FEATURE 1: Registro de productos

Registrar tenis
> Como administrador de inventario, quiero registrar un nuevo tenis con código, marca, modelo, talla, color, precio, stock y foto para tenerlo disponible en el sistema.

FEATURE 2: Consulta y búsqueda de productos

Consultar tenis
> Como vendedor, quiero consultar y buscar tenis por marca, talla o modelo para encontrar rápido el producto que pide el cliente.

FEATURE 3: Actualización de productos

Actualizar tenis
> Como administrador, quiero actualizar la información de un tenis existente para corregir precio, stock o descripción.


FEATURE 4: Desactivación de productos

HU-04 - Desactivar tenis
> Como administrador, quiero desactivar un tenis que ya no se comercializa para que no aparezca en ventas pero conserve su historial.
