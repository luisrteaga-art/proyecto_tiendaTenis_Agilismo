# Product Backlog - Tienda de Tenis

## Descripción del proyecto

Sistema para la gestión de una tienda de zapatos deportivos (tenis).
El sistema permitirá administrar productos, clientes, inventario,
pedidos, ventas, ofertas y proveedores.

---

- Consultar productos
- Actualizar productos
